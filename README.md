A program that writes one line to `/output/entry.txt` for the One Line to Your Younger Self bounty on make.fun: the single line its writer would send back to their younger self if one line were all they got.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
